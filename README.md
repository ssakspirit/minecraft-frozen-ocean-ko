# 얼어 붙은 행성 II: 얼음 바다 — 한국어 수업 자료

마인크래프트 에듀케이션 라이브러리 수업 「얼어 붙은 행성 II: 얼음 바다」(Frozen Planet II: Frozen Ocean)의 영문 수업 도움 자료를 한국어로 옮긴 **비공식 번역본**입니다.
원본의 배치·그림은 그대로 두고 글자만 한국어로 바꿨습니다. 같은 자료를 바로 고쳐 쓸 수 있는 원본 형식(pptx·docx)과 인쇄용 PDF로 함께 올립니다.

## 월드 열기

월드 파일은 이 저장소에 없습니다. 마인크래프트 에듀케이션 → 라이브러리에서 「얼어 붙은 행성 II: 얼음 바다」를 찾아 「만들기」를 누르거나, 공식 수업 페이지에서 여세요.

- 공식 수업 페이지: <https://education.minecraft.net/ko-kr/lessons/frozen-planet-ii-frozen-ocean>

월드는 한국어를 지원합니다(게임 언어를 한국어로).

## 자료 (`자료/` 폴더)

| 파일 | 내용 | 영문 원본 |
|---|---|---|
| 얼음바다_수업슬라이드.pptx / .pdf | 수업 슬라이드 11장 — 북극해, 북극곰, 도전 표(질문 8칸), 바다코끼리, 게임 안내 | Frozen Ocean Educator Deck |
| 얼음바다_북극곰_자료.docx / .pdf | 북극곰은 어떤 동물인지, 사는 곳, 생김새, 먹이 (1쪽) | Polar Bear Factsheet |
| 얼음바다_바다코끼리_자료.docx / .pdf | 바다코끼리는 어떤 동물인지, 사는 곳, 생김새, 먹이 (1쪽) | Walrus Factsheet |

- 대상: 모든 연령, 1시간 안팎 · 교과: 기후 과학
- 학습 목표: 북극해의 위치와 의미 알기 · 북극 동물이 사는 곳에 어떻게 적응했는지 조사하기 · 기후 변화가 북극해에 주는 영향 이해하기(SDG 13) · 바다 얼음이 줄면서 동물이 겪는 어려움 이해하기(SDG 13)
- 슬라이드 속 사진은 그림이라 바뀌지 않습니다. 학생 자료는 해요체로 옮겼습니다.
